# Saditha Udayanga — Python & AI Engineer Portfolio

This is a static GitHub Pages portfolio inspired by the interaction patterns and developer/CV presentation style of the CodePen reference you provided, including the code-themed loader, developer-style hero, timeline, project cards, responsive navigation, and scroll-reveal effects. The original reference is the CodePen "Tech resume template": https://codepen.io/doug-disbrow/pen/vEXeGKX

## Run locally

Open `index.html` directly, or run:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy

Repository name:

`saditha93.github.io`

Push the contents to the `main` branch and enable GitHub Pages from the repository root.
